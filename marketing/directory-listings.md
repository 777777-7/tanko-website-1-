# Directory listing pack — Primaxs

Paste-ready text for business directory submissions. **Use the exact same NAP
(Name, Address, Phone) everywhere** — inconsistent business details across
directories actively hurt local SEO, because Google treats mismatches as a
signal that it cannot verify the business.

**I could not submit these for you.** Every one requires creating an account,
which I am not able to do. Each takes about 5 minutes.

---

the phone as 03-42964737 in one place and +60 3-4296 4737 in another. Pick
these exact strings and reuse them.

## Long description (around 900 characters)

```
Primaxs Marketing (M) Sdn Bhd has been the exclusive Malaysia distributor for
Tanko Enterprise Co., Ltd. since 2006. Tanko has manufactured industrial
storage equipment in Taiwan since 1975.

Our catalogue covers approximately 1,700 SKUs across 11 ranges: industrial
workbenches in medium and heavy duty specifications, tool cabinets and roller
trolleys, CNC tool storage fitted for BT-30, BT-40, BT-50, HSK-40, HSK-63 and
ISO holders, modular workstations, steel lockers, parts and document cabinets,
warehouse racking, mould racks and perforated boards.

We hold stock in Selangor for popular configurations, with 3 to 7 working day
delivery nationwide. All quotations are issued in Malaysian Ringgit with unit
pricing, project pricing and delivery costs itemised separately. The Tanko
manufacturer warranty is administered locally from our Selangor office.

We supply manufacturing plants, automotive workshops, CNC machining shops,
laboratories and cleanrooms, electronics and EMS facilities, food and
pharmaceutical production, schools, campuses and technical training centres
across Malaysia.
```

## Per-listing checklist

For each directory, do all of these before moving on:

- [ ] Exact NAP from the block above — no abbreviations, no reformatting
- [ ] Category set to the closest match from the priority list
- [ ] Long description if the field allows it, medium if not
- [ ] Website link pointing to the **relevant category page**, not the homepage,
      where the directory is category-specific
- [ ] Logo uploaded (`docs/assets/primaxs-logo-removebg-preview.png`)
- [ ] At least 3 product photos from `asset3/`
- [ ] Business hours: Mon–Fri 09:00–18:00, closed weekends
- [ ] Year founded: 2006
