文件柜、A4 归档与文件托盘

有人叫它 文件柜, an A4 归档柜, a 文件托盘 或是文件托盘，取决于这份文件是要归档还是正在处理。关键的区别很简单：分格是把文件留在某个零件或订单旁边，托盘是让文件随流程往下走。生产办公室通常两者都需要，这也是它们被归在同一系列的原因。

选钢制，因为生产文件并不待在办公室里

流程卡、检验表与图面是待在产线上的，不是待在办公桌上。那就意味着油污、潮湿、叉车来往，以及偶尔整个搬到另一头 — 这些条件下，贴皮板柜子大约能撑一年，然后底板膨胀，抽屉就对不上滑轨了。

Tanko 的文件系列全部为钢制，涵盖 A4 分格柜与可堆叠托盘，尺寸是按文件本身而非按文具目录设定的。产品台湾制造，由自 2006 年起担任 Tanko 独家总代理的 Primaxs 在马来西亚供应，以马币报价，一年制造瑕疵保固由雪兰莪受理。雪兰莪与吉隆坡免费配送及安装；外州配送在报价单上单独列出。

常见问题 — 文件柜

文件柜在工厂里有什么用途？

A4 文件柜把品管记录、工单、图面与作业手册放在使用点上——桌上型或落地型——让文件在现场也能保持有序且随时可查。

桌上型还是落地型文件柜？

桌上型适合放在工作位旁、数量不多的文件；落地型则适合办公室与品管岗位较大的归档需求。按你需要随手可取的文件量来选。
