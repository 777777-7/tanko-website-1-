业界的各种叫法

同一块板，在不同的人口中至少有六七种叫法。 洞洞板 与 冲孔工具板 是原厂的叫法；保养班更可能直接向你要一块 工具展示板 或者干脆叫 工具板；而写 5S 作业标准的品管或精益工程师，会把同一样东西叫作 影子板管理，而图面上可能写的是 工具用冲孔板。它们指的都是这一系列。如果你拿到的规格表上写的是其中某一种叫法，又不确定是否对应得上，把图面发给我们，我们会替你核对孔距。

5S 要真有效，板子必须撑得过稽核之后

大多数影子板是做给照片看的。薄钢板在扫手斜着抽出时会变形，挂钩孔逐渐被拉长，不到几个月，板上的轮廓就对不上挂在上面的东西了。到那一步，板子就不再是一项管控手段，而只是装饰——工具又回到了抽屉里。

Tanko 的洞洞板与百叶板全系列采用固定孔距，因此今天买的挂钩、层板、料盒挂架、钻头支架与 T 型把手支架，仍然装得上多年前买的板子——同一批配件也可以在墙面面板、工作桌立柱与移动推车之间互相移用。产品台湾制造，由自 2006 年起担任 Tanko 独家总代理的 Primaxs 在马来西亚供应，以马币报价，并提供本地一年瑕疵保固。雪兰莪与吉隆坡免费配送及安装；外州配送在报价单上单独列出。

常见问题 — 洞洞板

洞洞板（pegboard）用来做什么？

洞洞板（pegboard）用来挂装挂钩、吊挂架与小料盒，让工具一目了然——这就是 5S 工作坊里影子板式工具管理的基础。

什么是影子板（Shadow Board）工具管理？

影子板管理，就是在板上画出每件工具的轮廓，让每件工具都有自己固定的位置。少了哪一件，一眼就看得出来，这是 5S 的核心做法之一。

你们有供应搭配 Tanko 洞洞板的挂钩吗？

有——Tanko 提供完整的钢制、塑胶与不锈钢挂钩、吊挂架及专用支架，均适配洞洞板孔距。告诉我们要挂什么工具，我们会替你推荐挂钩。
