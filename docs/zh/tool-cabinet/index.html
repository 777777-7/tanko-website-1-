工具柜、滚轮工具柜与工具箱

A 屉滚轮工具柜 是移动版本，工具箱通常叠在它上面，而工具柜则是固定式的那一种。三者采用相同的中央锁与相同的抽屉承重。如果柜子要在各作业区之间移动，脚轮与锁比抽屉数量更重要——一台没锁的带轮柜子，正是工具从工作坊消失的途径。

一台工具柜的成败，就在抽屉上

抽屉滑轨决定一台柜子能不能保住它的承重规格。滑轨一旦负载后发涩，就会被硬拉，不到一年那就成了一个没人愿意开的抽屉，而你买的柜子只剩三分之二在用。在共用的厂房里还有第二个问题：没有储物锁的柜子，会安静地把你的工具“分配”到全厂各处。

Tanko 的柜体与推车均在台湾制造，全系列配备中央锁，并按型号公开承重规格，移动式与包装推车机型最高达 400kg。抽屉的深度在出厂时就按真实工具尺寸定好，而不是为了凑一个好看的抽屉数。由自 2006 年起担任 Tanko 独家总代理的 Primaxs 在马来西亚供应——以马币报价，一年瑕疵保固由本地受理，不必运回台湾。雪兰莪与吉隆坡免费配送及安装；外州配送在报价单上单独列出。

常见问题 — 工具柜

工具柜和工具推车有什么区别？

工具柜是固定式柜体（通常配全拉出抽屉），用于在一个定点做高密度存放。推车或移动式工具箱则加上脚轮，让同一批工具可以在各作业区之间移动。很多马来西亚的工作坊会同时买一台固定柜加一台移动推车。

Tanko 工具柜的抽屉能承重多少？

抽屉承重依型号而异，但 Tanko 工业柜体均采用全拉出珠滑轨，承受得住每日工业使用，依系列不同每屉约 30-50 kg。请向我们确认你正在看的那个型号的确切规格。

抽屉的锁具牢靠吗？

是的——Tanko 工具柜配有中央锁系统，一把钥匙即可锁住所有抽屉，另可加装挂锁扭。在多人共用的工作坊里，这是工业柜体的标配。

工具柜能用在户外或潮湿的厂房吗？

标准粉体烤漆钢制柜体适合干燥的室内工作坊。若是潮湿或户外环境（在马来西亚相当常见），请指定防腐选配，或把柜子放在有髢蔽的位置。

马来西亚现货备有哪些尺寸的工具柜？

我们在雪兰莪备有常用尺寸的现货（例如 7-12 屉的滚轮柜与 2-3 排的抽屉柜）。更大或需要定制抽屉配置的机型，可按你的规格下单，并给出确认的交期。
